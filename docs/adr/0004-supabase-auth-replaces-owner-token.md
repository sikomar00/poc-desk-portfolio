# 로그인은 Supabase Auth로 하고, 서버 환경변수 토큰 방식(D-034)을 대체한다

가계부 접근을 Supabase Auth 계정(이메일·비밀번호, 가입 닫힘, 본인 1계정)으로 확인하고, 서버는 세션(JWT)만 검증한다. 가계부 조회는 여전히 서버의 직접 DB 접속으로만 이뤄진다(ADR 0002). 사용자가 1명이라 토큰이 더 단순하지만, 계정 로그인이 있어야 "로그인한 본인"과 "공개 데모"를 화면·기록에서 구분할 수 있고, 비밀번호 저장·세션을 직접 만들지 않아도 된다.

## Considered Options
- 서버 환경변수 토큰(D-034): 가장 단순하지만 사용자 구분과 실행 기록의 `user_id`를 만들 수 없어 대체.
- 자체 `users` 테이블: 비밀번호 해시·재설정을 직접 구현해야 해서 기각.
