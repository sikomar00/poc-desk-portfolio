# Vercel 공개 배포

## 요약
앱(realDefinition)을 **누구나 접속할 수 있는 공개 데모**로 배포했습니다: **https://realdefinition.vercel.app**. 데이터는 합성(가짜) 주문 데이터뿐이고 Supabase(서울)에서 읽습니다. 로그인은 본인 계정만 되며, 비로그인은 계산·정의 비교만 할 수 있습니다. 같은 코드가 내 PC(로컬)에서도 그대로 돕니다. 공개 모드는 환경변수 `POC_DESK_PUBLIC=1`일 때만 켜집니다.

> 📘 **개념 학습 — 서버리스 함수와 Vercel**
> - **서버리스 함수**: 서버를 계속 켜 두지 않고, 요청이 올 때만 코드를 잠깐 실행하는 방식. 요청이 없으면 꺼져 있다가(콜드 스타트) 다음 요청에서 다시 깨어난다.
> - **Vercel**: GitHub 저장소의 코드를 받아 서버리스 함수로 배포해 주고, 주소(도메인)와 HTTPS를 붙여 준다.
> - **환경변수**: 비밀번호처럼 코드에 넣으면 안 되는 값을 배포 서비스의 비밀 저장소에 따로 보관해 코드가 실행될 때만 주입하는 방법.
> - **배포 보호**: Vercel이 기본으로 켜 두는 "Vercel 로그인한 사람만 접속" 잠금. 공개 데모는 이것을 꺼야 한다.

## 1. 구조
```
브라우저 ──https──▶ Vercel (서울 icn1, Python 3.12 서버리스 함수 api/index.py)
                       │  같은 서버 코드 app/server.py 를 그대로 실행
                       ├─ 계산·정의 비교: poc_reader_demo 역할 (읽기 전용, 5초 제한, demo 스키마만) ─▶ Supabase 서울
                       └─ 원장·정의·기록: app_service 역할 (추가만 가능)                           ─▶ Supabase 서울
브라우저 ──https──▶ Supabase Auth (로그인은 브라우저가 직접)
```
- `vercel.json`: 모든 요청을 한 함수로 보낸다(`/api/index?__vp=원래경로`). 서버가 원래 경로를 되돌려 화면·API를 구분한다.
- `.vercelignore`: 비밀·개인 데이터·큰 파일을 올리지 않는다.
- **Vercel에 올린 비밀은 두 개뿐**: 읽기 전용 계산 역할과 서비스 역할의 비밀번호(민감 값으로 저장, 다시 볼 수 없음). **가계부 역할의 비밀번호와 DB 관리자 비밀번호는 올리지 않았다**(최소 권한).

## 2. 공개를 위해 바꾼 것 (내 PC 전용 규칙 → 공개 규칙)
| 항목 | 내 PC 전용 | 공개 데모 |
|---|---|---|
| 접속 주소 | `127.0.0.1`만 허용 | 모든 도메인 허용 |
| 다른 사이트에서 보낸 요청 | Origin이 로컬이 아니면 거절 | **Origin이 접속한 주소와 같지 않으면 거절**(같은 출처만) |
| 비로그인 실행 기록 | DB에 남김 | **남기지 않음**(누구나 DB에 행을 쌓지 못하게) |
| 사용자 정의 지표 저장 | 가능 | **끔**(파일이 영구 저장되지 않고 작성자도 보장할 수 없다) |
| 속도 제한 | 없음 | 같은 접속자 60초에 90회(서버리스에서는 인스턴스별 근사치) |
| HTTPS 강제 헤더 | — | `Strict-Transport-Security` |
| AI 모드 | 키가 있으면 가능 | **로그인한 본인만**(비로그인은 선택 불가·API 401). 키는 **운영 환경에만** 민감 값으로 등록(미리보기 배포에는 없음). 모델 `gpt-oss-20b`, 호출 대기 50초 제한 |
| 실행 기록·리포트 | 본인 로그인 | 본인 로그인(변함없음) |

## 3. 배포하면서 발견한 문제 (그리고 고친 방법)
| # | 증상 | 원인 | 조치 |
|---|---|---|---|
| 1 | 접속하자 우리 서버가 "허용되지 않은 접속 주소" 거절 | 함수 안에서 코드가 정한 기본 환경변수가 유지되지 않았다(`env=None`을 로그로 확인) | 설정을 코드 기본값이 아니라 **Vercel 프로젝트 환경변수**로 직접 넣음 |
| 2 | 모든 화면·API가 404 | Vercel이 요청 경로를 `/api/index`로 바꿔 전달해 앱이 원래 주소를 몰랐다 | rewrite에 원래 경로를 쿼리로 실어 보내고 서버에서 복원, 테스트 추가 |
| 3 | 정의 비교 12초, 단일 실행 3.7초 | 요청마다 DB 연결을 새로 열고(연결당 약 1.3초, 쿼리는 0.19초) 닫았다 | 연결을 재사용(서비스 역할은 슬롯을 붙잡지 않는 **트랜잭션 모드 포트 6543**) → 첫 요청 약 4초, 이후 **약 1초, 정의 비교 약 1.9초** |
| 4 | 읽기 전용 역할에 `search_path`를 역할 기본값으로 주면 풀러에서 적용되지 않음 | 읽기 전용·5초 제한은 적용되는데 검색 경로만 안 됨(풀러 동작) | 마이그레이션 0007로 되돌리고, 읽기 전용 역할은 세션 모드에서 접속 직후 설정 |
| 5 | 진단용으로 넣은 로그 줄이 문법 오류로 배포를 깨뜨림 | 줄바꿈 이스케이프 실수 | 로그의 `SyntaxError`로 즉시 발견, 수정, 임시 진단 코드는 모두 제거 |

### 공개 주소에서 직접 시험한 것 (2026-10-20)
| 시험 | 결과 |
|---|---|
| 다른 사이트 출처(Origin)로 POST | 403 거절 (같은 출처는 200) |
| `X-PocDesk` 헤더 없음 / `text/plain` | 403 / 415 |
| 상태 조회 110회 연속 | 87회 성공 후 **429**로 막힘(같은 접속지는 60초 뒤 풀림) |
| 응답 헤더 | CSP(연결은 자기 자신과 Supabase만), HSTS, nosniff |
| 비로그인: 정의 저장 / 기록 / 리포트 | 403 / 401 / 401 |
| 정의 비교 6개 값, 1분기 매출 대사 | 정확(82,537,900 ~ 62,831,000원, 원장 일치) |
| 응답 속도 | 첫 요청 약 4초(콜드 스타트), 이후 약 1초, 정의 비교 약 1.9초 |

## 4. 알려진 한계 (정직하게)
- **속도 제한은 완전한 방어가 아니다.** 서버리스는 인스턴스마다 메모리가 따로라서 "접속자당 90회/분"은 근사치다. 실제 남용 방어는 Vercel의 방화벽·플랜 기능이 필요하다.
- **콜드 스타트**: 한동안 요청이 없으면 첫 요청이 약 4초 걸린다.
- **Hobby(무료) 플랜**은 비상업·개인 용도 약관이다. 포트폴리오 데모는 해당하지만 상업적으로 쓰려면 플랜을 바꿔야 한다.
- 공개 앱에서 **로그인 가능한 계정은 본인뿐**이고(가입 닫힘), 로그인해도 공개 모드에서는 정의 저장이 꺼져 있다.
- **방문자는 AI 모드를 직접 쓸 수 없다.** 서버의 AI 키를 누구나 쓰게 하면 요금이 나가고 남용될 수 있고, 모델 응답이 10~44초로 함수 시간 제한(60초)에 가까워 불안정하기 때문이다. 방문자가 AI 쪽을 볼 수 있게 하려면 실험에서 기록한 실제 모델 출력을 재생하는 방식이 다음 후보다.
- **AI 모드 호출 응답은 느리다**(공개 주소에서 31.5초). 한도 60초 안이지만 모델이 느린 날에는 시간 초과로 실패할 수 있다(실패하면 오류로 기록).
- 리포트 파일은 서버리스의 임시 저장소(`/tmp`)에 쓰므로 서버 쪽에는 남지 않는다. 화면에서 내려받은 파일만 남는다.
- 가계부(`personal`)는 이 배포와 연결하지 않았다. 접속 비밀번호도 올리지 않았다.

## 5. 다시 배포하는 법
```powershell
npx vercel login                          # 한 번(브라우저 승인)
npx vercel deploy --prod                  # 수동 배포
```
GitHub의 Vercel 앱을 이 저장소 하나에만 설치해 연결했고(2026-10-20), **`main`에 푸시할 때마다 자동으로 운영 배포**가 된다. 다른 브랜치 푸시는 미리보기 배포가 된다. 확인: 문서 커밋 `bb466b4`를 푸시하자 사람이 배포 명령을 실행하지 않았는데 새 운영 배포가 25초 안에 생겼고 GitHub 커밋에 "Vercel — Deployment has completed — success" 상태가 붙었다.

필요한 환경변수(Vercel 프로젝트에 등록, 값은 저장소에 없다):
| 이름 | 종류 |
|---|---|
| `POC_DESK_BACKEND=supabase`, `POC_DESK_PUBLIC=1`, `POC_DESK_DB_PERSIST=1`, `POC_DESK_DATA_DIR`, `POC_DESK_REPORT_DIR` | 동작 설정 |
| `SUPABASE_PROJECT_REF`, `SUPABASE_URL`, `SUPABASE_POOLER_HOST`, `SUPABASE_POOLER_PORT=6543`, `SUPABASE_ANON_KEY` | 접속 정보(공개 값) |
| `POC_READER_DEMO_PASSWORD`, `APP_SERVICE_PASSWORD` | **비밀(민감 값)** |
| `NVIDIA_API_KEY` | **비밀(민감 값), 운영 환경에만** |
| `LLM_MODEL=openai/gpt-oss-20b`, `POC_DESK_LLM_TIMEOUT=50` | 모델·호출 대기 시간(비밀 아님) |

## 열린 질문
- 공개 데모에 방화벽 규칙(IP당 요청 수)을 걸지(Vercel 방화벽, 플랜에 따라 다름).
- 도메인을 `vercel.app` 대신 직접 구입한 주소로 쓸지.
