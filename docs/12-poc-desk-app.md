# realDefinition 앱

## 요약
[04 문서](04-journey-and-flow.md)에서 설계한 크리티컬 여정(질문 → 정의 확인 → 계산 → 정답 대조 → 리포트)을 **실제로 눌러 볼 수 있게** 만든 로컬 웹앱 시제품입니다. 추가 설치 없이 Python만으로 실행되고, 합성 데이터에서만 동작합니다.

**이 앱이 보여 주는 것:** 정의가 확정되지 않은 지표는 계산하지 않고, 정답 출처가 없는 숫자에는 "검증됨"을 붙이지 않으며, 틀린 숫자는 경고한다는 실험 결과(07, 09)의 설계 원칙입니다.

**솔직한 상태:** 계산식 모드와 대사, 리포트, 사전, 기록은 테스트와 브라우저로 확인했습니다. **AI 모드는 처음에는 가짜 LLM으로만 확인했고(키 없음), 이후 실제 모델(`openai/gpt-oss-20b`)로 앱의 AI 모드를 로컬 5회·공개 주소 1회 호출했고 모두 원장·기준 계산식 대조를 통과했습니다(`nemotron-3-super-120b`도 1회 통과했으나 44초로 서버 한도에 가까움). **표본이 작아 정확도를 주장하지 않습니다.** AI에게 KPI 사전을 함께 주는 조건(실험의 B2)이라 정답이 많이 나오는 것은 예상된 결과이며 실험 결론을 바꾸지 않습니다.**

## 정의 비교 (같은 질문, 다른 정의, 다른 숫자)
정의 확인 화면과 결과 화면의 **"정의가 다르면 숫자가 얼마나 달라질까?"** 카드에서 `6가지 정의로 비교하기`를 누르면, 같은 기간의 '매출'을 정의 6가지(V0~V5)로 나란히 계산해 보여 준다.
- 각 정의는 네 가지 선택(어떤 주문 · 어떤 금액 · 취소·환불 처리 · 기준일)로 풀어 쓰고, 공식 정의(V5)는 원장과 정확히 일치하는지 함께 표시한다.
- 합성 데이터 1~3월 기준 결과: **62,831,000원(공식)부터 82,537,900원(주문 총액)까지, 최대 19,706,900원(31.4%) 차이.**
- 계산식은 새로 만들지 않고 실험·문서에서 쓴 `data/verify_definitions.py`의 6가지를 그대로 쓴다. Supabase에서는 날짜 함수만 바꿔 실행하며, 두 DB에서 18개 월별 값이 모두 같다.
- 지금은 '매출'에만 있다(다른 지표는 정의 변형이 아직 없다). 로그인 없이 쓸 수 있고 실행 기록에는 남지 않는다.

## Supabase 모드 (합성 데이터를 클라우드 DB에서 읽기)
기본은 로컬 SQLite 파일이다. Supabase(서울 프로젝트)의 합성 데이터로 돌리려면 `.env`에 접속 정보가 있어야 하고, 서버를 시작하는 창에서 한 줄을 더 설정한다.
```powershell
cd C:\realDefinition
$env:POC_DESK_BACKEND = 'supabase'
python app/server.py
```
- 처음 한 번: `python -m pip install --target app/_vendor -r requirements.txt` (접속 도구 pg8000). `.env`의 값(접속 정보)은 [14 문서](14-supabase-spec-and-tickets.md)와 `app/db.py` 머리말을 본다.
- 화면 오른쪽 위에 **로그인**이 생긴다. 로그인 없이도 합성 데이터 계산은 되고, **실행 기록·리포트·사용자 정의 저장**은 본인 계정만 한다.
- 상단 배지에 `데이터: Supabase(서울)` 또는 `데이터: 로컬 SQLite`가 표시된다.

## 1. 실행 방법

```powershell
$env:NVIDIA_API_KEY = (New-Object System.Net.NetworkCredential("", $s)).Password
```

## 4. 설계 결정

**D-029 설치가 필요 없는 로컬 웹앱으로 만든다.** Python 표준 라이브러리 서버와 순수 HTML·CSS·JS입니다. 이유: 채용 담당자가 `python app/server.py` 한 줄로 실행할 수 있고, 외부 패키지가 없어 의존성 위험도 없습니다. 버린 대안은 Streamlit(설치 필요, 코드는 짧음), Flask(설치 필요), Electron(과함)입니다. 비용: 화면 코드를 직접 작성해야 해서 길어집니다.

**D-030 두 실행 방식을 모두 제공하고 "검증됨"의 조건을 엄격히 한다.**
- *검증된 계산식 모드*: 사람이 검토한 SQL을 실행합니다. 07·09 문서에서 오답이 모델의 체계적 습관이라는 것을 확인했고, 그래서 시맨틱 레이어 방식(LLM이 SQL을 새로 짜지 않음)이 근본 해법일 수 있다고 본 가설의 **시제품**입니다. 이 방식은 아직 실험으로 평가하지 않았습니다.
- *AI 모드*: LLM이 SQL을 만들고 기준값과 원장에 대조합니다.
- 정답 출처가 없는 지표는 어떤 방식이든 **"검증 불가"** 로 표시합니다(D-025).

## 5. 보안 설계
- **내 PC에서만 접속**(127.0.0.1에만 바인딩). 다른 웹사이트가 이 서버로 요청을 보내는 것을 막기 위해 Host·Origin 검사, JSON 요청만 허용, 사용자 지정 헤더 확인을 합니다.
- **API 키는 환경 변수**로만 읽고 화면·응답·기록으로 나가지 않습니다(키가 있는지 여부만 표시).
- **AI에는 테이블 구조와 사전만** 보냅니다. 거래 행도, 정답표(`ledger`)도 보내지 않습니다.
- LLM이 만든 SQL은 **읽기 전용 한 문장**만 실행합니다. 쓰기·변경 키워드, 여러 문장, 정답표 접근은 실행 전에 차단합니다.
- 화면의 모든 문자열은 DOM API(텍스트 노드)로만 넣어 스크립트가 실행될 틈을 막고, 콘텐츠 보안 정책(CSP)으로 외부 스크립트를 차단합니다.

## 6. 검증한 것과 못한 것

| 검증함 | 방법 |
|---|---|
| 질문 20개의 계산 결과가 골드와 일치, 매출은 원장과 정확히 일치 | `app/test_app.py` |
| 기간·지표 해석, 사전 4항목 필수와 버전, 사전에 없는 지표 실행 거부 | 단위 테스트 |
| AI 모드의 통과·경고·차단·검증 불가·키 없음 처리, 프롬프트에 정답표가 없음 | 가짜 LLM 테스트 |
| 서버 보안(외부 Host·Origin 거부, 형식·크기 제한, 경로 탈출 차단, 키 비노출) | HTTP 테스트 |
| 화면 흐름 전체(통과, 경고, 차단, 새 지표 정의 폼, 리포트, 기록, 휴대폰 폭) | 브라우저에서 직접 조작. 콘솔 오류 없음 |

**검증 중에 찾아 고친 오류:** 테스트를 반복 실행하다가 약 40% 확률로 실패하는 것을 발견했습니다. 원인은 테스트가 아니라 **서버의 버그**였습니다. 서버가 요청을 거절할 때 본문을 읽지 않고 응답하면, 클라이언트가 본문을 보내는 도중 연결이 끊겨 거절 응답을 받지 못합니다(브라우저에서도 같은 문제가 날 수 있음). 응답 전에 본문을 먼저 읽도록 고쳤고, **고치기 전 코드에서는 실패하고 고친 뒤에는 통과하는 회귀 테스트**를 추가했으며, 테스트 21개를 25회 반복해 모두 통과했습니다(D-031). 한 번 통과한 테스트를 반복해서 돌려 보지 않았다면 놓쳤을 문제입니다.

**코드 리뷰 반영 (D-032):** 리뷰에서 나온 지적을 모두 수정했다. 예를 들어 "1월, 2월, 3월"에서 3월이 빠지던 기간 해석, 정의해 둔 지표를 다시 인식하지 못하던 질문 해석, 같은 달이 두 번 들어오면 정답이 경고가 되던 대사, 사용자 정의 지표를 "원"으로 표시하던 리포트, 동시 저장 시 사전이 덮어써지던 문제, 키보드 포커스 유실, 서버의 소켓 시간 제한 부재가 포함된다. 각 수정에는 **수정 전 코드에서 실패하는 회귀 테스트**를 붙였고, 수정한 동작을 일부러 되돌리는 변이 시험으로 테스트가 결함을 잡는지도 확인했다.

| 못한 것 | 이유·영향 |
|---|---|
| **실제 LLM을 앱에서 호출** | 이 환경에 키가 없음. 가짜 LLM으로 경로만 확인함 |
| 스크린 리더, 다른 브라우저, 큰 글씨 시험 | 레이블·키보드 조작·대비는 고려해 만들었으나 도구로 점검하지 않음 |
| 여러 사람이 동시에 사용 | 범위 밖 |

## 7. 한계
- 합성 데이터 3개월에서만 동작하며 실제 고객 데이터 연동이 없습니다.
- 질문 해석이 키워드 규칙이라 새 표현에 약합니다.
- 계산식 모드는 내장 5개 지표만 지원하고, 새로 정의한 지표는 AI 모드로만 계산되며 항상 "검증 불가"입니다.
- 결과는 숫자 하나만 지원합니다(표, 그래프 없음).
